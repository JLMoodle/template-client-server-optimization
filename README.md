# Правила Git

После каждой лабораторной работы необходимо создать commit.

Формат:

```text
Lab XX: Description
```

Например:

```text
Lab 01: Initialize GitHub repository
```

```text
Lab 02: Create HTML structure
```

```text
Lab 03: Add CSS styling
```
